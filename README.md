## 📌 Sobre o Projeto

O **Conectando Serviços** é um sistema desenvolvido para simplificar a busca, contratação e gerenciamento de serviços. A plataforma aproxima profissionais autônomos e prestadores de clientes finais, permitindo agendamento dinâmico, consulta de disponibilidade e gestão transparente de solicitações.

Este projeto foi desenvolvido aplicando boas práticas de arquitetura de software, modelagem de dados relacional e princípios de usabilidade.

## ✨ Funcionalidades Principais

- 👥 **Cadastro e Autenticação de Usuários:** Perfis diferenciados para *Clientes* e *Prestadores de Serviço*.
- 🔍 **Busca e Filtro de Serviços:** Localização de profissionais por categoria e especialidade.
- 📅 **Gestão de Agendamentos e Solicitações:** Criação, acompanhamento e atualização do status de atendimento.
- 📊 **Painel do Prestador:** Visualização de serviços solicitados e histórico de atendimentos.
- 💬 **Transparência de Status:** Acompanhamento dinâmico do fluxo do pedido.
